# Acta de Acuerdo: Política de Transparencia y Uso de Inteligencia Artificial

**Fecha:** 05 de octubre de 2026
**Hito:** 1.1 Fundaciones Técnicas
**Asistentes (Roles):** Equipo completo (Tech Lead, Backend, Frontend, QA/DevOps)

## 1. Objetivo del Acuerdo
El presente documento formaliza el compromiso de todos los miembros del equipo de desarrollo del **Sistema Web Inteligente para la Gestión Integral de Servicios Universitarios** de cumplir estrictamente con las políticas de honestidad académica y trazabilidad exigidas en la rúbrica del proyecto.

## 2. Reglas Aprobadas
Por decisión unánime del equipo, se establecen las siguientes reglas inquebrantables durante todo el ciclo de vida del proyecto (Fase I a Fase III):

1. **Uso Permitido:** Se autoriza el uso de agentes de IA (como Antigravity, GitHub Copilot, ChatGPT, Claude, etc.) para tareas de andamiaje (*scaffolding*), refactorización, generación de datos de prueba, y escritura de documentación o *boilerplates*.
2. **Registro Obligatorio:** Todo uso sustancial de IA (aquel que genere lógica de negocio, arquitectura, o componentes completos) **DEBE** ser registrado inmediatamente en el archivo personal del rol dentro de `docs/04-gestion/ia-registro/` (las reglas oficiales están en `docs/04-gestion/ia-register.md`).
3. **Formato de Registro:** El registro debe incluir el prompt utilizado, la herramienta de IA, el código o artefacto modificado, y una evaluación humana obligatoria. **No se permite copiar y pegar a ciegas**.
4. **Verificación en Pull Requests:** El Tech Lead (R1) y el QA (R6) se reservan el derecho de rechazar cualquier *Pull Request* que contenga código de alta complejidad que no esté acompañado de su respectiva entrada en el registro de IA.

## 3. Compromiso y Firmas
Todo el equipo se da por enterado de estas reglas y entiende que la omisión de las mismas puede resultar en penalizaciones graves por parte de la evaluación docente. 

Este acuerdo entra en vigencia a partir de la creación de la rama `develop` y aplica para todos los módulos del proyecto.
